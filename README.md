# One Day — Day One
## About

This project is an interactive generative city made with p5.js. Each time the page loads, it generates a new city with a variety of building shapes and colours.

Scroll down to watch the water rise and the city sink beneath it. The visual scene is an artistic interpretation of rising sea levels. It serves as a warning about the impacts of climate change, particularly rising sea levels.

## How to Run

You need Python 3 and a modern web browser. An internet connection is required to load p5.js from its CDN.
